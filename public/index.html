API Reference

Base URL:

MethodEndpointDescription
GET/api/productsList catalogue (params: category, search)
GET/api/products/:idGet single product with stock status
POST/api/productsAdd new product
PUT/api/products/:idUpdate product details
DELETE/api/products/:idDelete product
GET/api/inventoryFull inventory list
PATCH/api/inventory/:productIdSet stock qty / threshold
POST/api/inventory/:productId/restockAdd stock (restock)
GET/api/ordersList all orders (param: status)
GET/api/orders/:idGet order details
POST/api/ordersPlace order (auto-deducts inventory)
PATCH/api/orders/:id/statusUpdate order status (cancel restores stock)
