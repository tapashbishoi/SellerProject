🔌 How to connect

// Add to ~/Library/Application Support/Claude/claude_desktop_config.json { "mcpServers": { "seller": { "url": "https://sellerpos.onrender.com/mcp", "headers": { "X-API-Key": "buyer-key-001" } } } }
# Run in terminal — adds MCP server to Claude Code claude mcp add seller \ --url https://sellerpos.onrender.com/mcp \ --header "X-API-Key: buyer-key-001" # Verify it's registered claude mcp list
# All requests: POST /mcp with these headers curl -X POST https://sellerpos.onrender.com/mcp \ -H "Content-Type: application/json" \ -H "Accept: application/json, text/event-stream" \ -H "X-API-Key: buyer-key-001" \ -d '{"jsonrpc":"2.0","id":1,"method":"tools/list","params":{}}'
# Machine-readable server discovery GET https://sellerpos.onrender.com/.well-known/mcp.json # Returns: endpoint URL, tool count, auth requirements, categories # Use this to auto-configure MCP clients programmatically

🛒 Typical Buyer Flow

1. register_buyer — save your office address once → nearest DC auto-assigned → 2. browse_catalogue — find products, see prices & stock → 3. check_delivery_options — see which DC fulfills, shipping days & cost before ordering → 4a. place_order — order at list price (address & DC auto-loaded)    or 4b. negotiate_price → accept_counter_offer — negotiate (shipping zone affects discount) → 5. track_order — follow status + see fulfilling DC → 6. list_my_orders — view full order history
